# Eval harness (Python, offline only)

`run.py` runs `dmn replay` on every fixture under `testdata/`, reads the session log, and reports question recall, precision and question-end → Approach latency (p50, p95). Lands with issue #10; Python is not used anywhere on the audio path.

Ground truth is `testdata/<fixture>/questions.json` (positives) and `turns.json` (every turn, so non-question interviewer turns are the negatives). The fixtures themselves are generated by `tools/fixtures/` (`just fixtures` to regenerate, `just fixtures-fetch` to download); see `testdata/README.md`.
